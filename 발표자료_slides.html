무엇을 / 왜 만들었나

와이어프레임 단계에서 색을 적용해 보려면 디자인 툴에서 매번 수작업이 필요하다.
MWV는 블럭 배치 → 2색 지정 → 즉시 반영으로 컨셉 컬러를 수 초 안에 검증한다.

핵심 가치

  • 그레이 와이어프레임 ↔ 컬러 적용을 토글로 즉시 비교
  • Primary / Secondary 2색만으로 컨셉 전달
  • 비전문가도 블럭을 끌어다 화면 구성 가능

대상 사용자

  • 직접 만드는 사람 — 빈 캔버스에 블럭 배치
  • 빠르게 시작하는 사람 — 템플릿 선택 후 색만 조정
  • 색 조합안을 여러 개 저장·비교하려는 사람

주요 기능 & 기술

1블럭 에디터 — 제목·텍스트·버튼·이미지·박스·아바타·뱃지·구분선을 클릭/드래그앤드롭으로 배치, 핸들 리사이즈, 옆·아래 자유 배치, 넘치면 가로·세로 스크롤
2속성 조절 — 선택 블럭의 텍스트·폰트 크기·너비/높이·색 역할(기본/Primary/Secondary)
3컬러 시스템 — HEX·컬러피커로 2색 지정, ON/OFF 토글, 버튼 글자색 자동 대비
4캔버스 — 배경색 지정, 상단바 iOS / Android 전환
5템플릿 & 저장 — 대시보드·피드·상세·갤러리·로그인 템플릿 로드, 디자인을 리스트로 저장·불러오기

기술 스택

  • 순수 HTML / CSS / Vanilla JS (빌드 없음)
  • 상태 저장: 브라우저 localStorage
